# .spw — the hypersemantic tree over Dragon's Egg

This is a parallel semantic topography of the breadstuffs repo. It does not
document the code; it **summons** it. The crystallized substrates — Rust, Lean,
the .md goal lanes — hold what the system *is*. These surfaces hold what the
system *means*, compressed to the density an LLM can load as a latent field:
names, strata, tensions, valences, wonder.

Read order for a machine visitor:

1. `root.spw` — the four-line poem-map. The whole repo in four operators.
2. `topography/strata.spw` — the poem expanded into real directory families.
3. `lenses/` — attentional substrates: each lens loads one region for ideation.
4. `index.spw` — routing table; `shelves.spw` — `@root` aliases for navigation.

The workbench is mounted at `_workbench/`. Sense loop from there:

```sh
cd .spw/_workbench
npm run spw:invent -- ../../.spw --sort degree
npm run spw:map    -- ../../.spw
npm run spw:skim   -- ../root.spw
```

Editing stance: surfaces here are deliberately more fluid than the code they
shadow — reshape them freely during ideation; the repo's canon lives in the
crystal, not the tree. When a lens hardens into fact, promote it to docs/ or a
GOAL lane and leave a `~"path"` back-reference.
