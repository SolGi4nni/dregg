# lean-ratchet-dark-allow.txt — modules that are DARK to `#floor_ratchet` / `#teeth_wired`
# and are recorded here as deliberate. Gate: scripts/check-ratchet-darkness.sh.
#
# WHY THIS FILE EXISTS
#   `#floor_ratchet` (the refuted-floor ACCRUAL gate) and `#teeth_wired` (the tooth-wiring
#   roster) are Lean commands at the end of `metatheory/Dregg2.lean`. They read the elaborated
#   environment — which is EXACTLY that root's transitive import closure. `lakefile.toml` has
#   FIVE default targets and only one of them is that root: `Metatheory.+` and `Polis.+` are
#   GLOBBED (every file is its own target), and `Market`/`Bfv` are separate roots. So a
#   declaration outside the Dregg2 closure can take a hypothesis this tree PROVES FALSE at
#   deployed BabyBear parameters, compile green in the default build, pass its own
#   `#assert_axioms` — and be invisible to the gate built to catch exactly that.
#
#   Measured at the commit that added the gate (clean `git archive` export): 201 of 2029 in-tree
#   modules dark, 75 of them still BUILT by lake. Nine dark modules mentioned a refuted floor
#   (101 mentions). The ratchet baseline's own `manual +56` raise is this bypass running in
#   reverse: rooting six dark modules surfaced 56 already-vacuous theorems that had been hiding.
#
# THE RULE THIS FILE RECORDS
#   A dark module that MENTIONS A REFUTED FLOOR gets ROOTED, not listed. Exempting one needs the
#   literal token `FLOOR-EXEMPT:` on its line plus a reason — a loud, greppable spelling, because
#   "it is scratch" is not a reason to hide floor-carrying content from this gate. Everything
#   else here is RULE 2: built by lake, outside the ratchet's environment, recorded so the
#   surface cannot grow silently.
#
# ⚠ WHAT A LINE HERE DOES *NOT* SAY
#   It says the exclusion is DELIBERATE. It does NOT say the module is counted by any
#   instrument. A listed module's declarations are absent from every `#floor_ratchet` number,
#   from `#floor_census`, and from the baseline — the campaign's counts are counts of the Dregg2
#   root closure, and this file is the measured statement of what they leave out.
#
# FORMAT  one dotted module per line, optional `# reason` after it. Blank/`#` lines are comments.
#         Staleness is checked: an entry that got rooted, an entry whose file is gone, a
#         `FLOOR-EXEMPT:` entry that no longer mentions a floor, and an entry that records
#         nothing (not built, no floor mention) each FAIL the gate.
